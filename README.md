# to3gp.sh
Convenience tool for ffmpeg for converting mp4 to 3gp (mainly for nokia 3310 2017)

# Usage:
``` chmod +x ./to3gp.sh ```
> this is to allow ./to3gp.sh running permissions

``` ./to3gp.sh filepathORname1.mp4 filenameORpath2.mp4 ```
> you can add as many mp4 files afterwards

## Output will be the same as the filename, just with .3gp at the end. It will become 240p@8fps
